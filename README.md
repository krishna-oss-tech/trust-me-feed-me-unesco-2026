## 📌 Executive Summary & Problem Statement

Today's youth encounter hundreds of algorithmic inputs every hour through AI chatbots, TikTok, Instagram, YouTube, news outlets, and online communities. 

When evaluating online content, people frequently trust information because:
- **It sounds confident & articulate** (AI Hallucination risk)
- **The logo/interface looks professional** (Brand impersonation)
- **It has thousands of likes and shares** (Bandwagon bias & astroturfing)
- **It matches what they already believe** (Confirmation bias)
- **They lack time to verify** (Fast-trust habits)

Most media-literacy tools ask a binary question: *"Is this true or false?"*

**TRUST ME, FEED ME** asks three deeper, transformative questions:
1. **"Why did you trust it?"** (Conscious reflection on behavioral biases)
2. **"How could you verify it?"** (The UNESCO 6-Point MIL Audit)
3. **"What kind of information environment did your choices create?"** (Simulated Recommendation Feed)

## 🔍 The UNESCO 6-Point MIL Audit Framework

When users select **VERIFY**, they engage with an interactive panel teaching the 6 foundational checks:

1. 🌐 **SOURCE**: Who created or published this? Are they verifiable and accountable?
2. 📅 **DATE**: When was this released? Is archival media being recirculated?
3. 📄 **EVIDENCE**: What primary data, studies, or documents back the claim?
4. 🔎 **CONTEXT**: What critical background or qualifying context is missing?
5. 🖼️ **MEDIA**: Is the image, video, or audio authentic and directly tied to the event?
6. 👥 **CONSENSUS**: Do independent scientific or international consensus bodies agree?

> 💡 **Core Takeaway**: *"Confidence is not evidence. Slick presentations can disguise missing sources."*

## 📊 Behavioural Scoring Engine

The platform uses a transparent, deterministic rule-based engine (`src/engine/scoringEngine.ts`) rather than opaque black-box machine learning:

$$\text{FastTrust} = \left(\frac{\text{TrustCount}}{\text{TotalScenarios}}\right) \times 100$$

$$\text{VerificationHabit} = \left(\frac{\text{VerifyCount}}{\text{TotalScenarios}}\right) \times 100$$

$$\text{EmotionInfluence} = \left(\frac{\text{EmotionTrustMatches}}{\text{TotalHighEmotionScenarios}}\right) \times 100$$

$$\text{SocialProofInfluence} = \left(\frac{\text{SocialProofTrustMatches}}{\text{TotalHighSocialProofScenarios}}\right) \times 100$$

$$\text{AITrust} = \left(\frac{\text{AITrustMatches}}{\text{TotalAIGeneratedScenarios}}\right) \times 100$$

$$\text{AccuracyScore} = \left(\frac{\text{CorrectDecisions}}{\text{TotalScenarios}}\right) \times 100$$

### Behavioural Archetypes Generated:
- **Systematic Verification Champion**: High pause-and-reflect habit; resistant to viral pressure.
- **Engagement-Sensitive Reader**: Responsive to high like counts and emotional narratives.
- **AI-Optimistic Navigator**: Receptive to synthetic summaries; learns prompt audit skills.
- **Rapid Information Streamer**: Fast processing speed; practices domain inspection.
- **Balanced Information Navigator**: Nuanced, flexible evaluation across diverse media.

*(Clear ethical disclaimers are always presented to clarify that these indicators reflect interactive choices, not psychological diagnoses).*

## ⚡ Quick Start / Local Development

### 1. Clone the repository
```bash
git clone https://github.com/krishna-oss-tech/trust-me-feed-me-unesco-2026.git
cd trust-me-feed-me-unesco-2026
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

## 🌐 Deploy to Vercel

The project is pre-configured with `vercel.json` for one-click deployment:

1. Push this repository to GitHub.
2. Log into [vercel.com](https://vercel.com) and click **"Add New..." $\rightarrow$ "Project"**.
3. Select `trust-me-feed-me-unesco-2026`.
4. Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. (Optional) Configure environment variables in Vercel:
   - `AI_API_KEY`: *(Server-Side secret: OpenAI / compatible API key used by `/api/ai-analysis` & `/api/verify-claim`)*
   - `TAVILY_API_KEY`: *(Server-Side secret: Tavily Search API key used by `/api/verify-claim`)*
   - `VITE_SUPABASE_URL`: *(Client-Side: Optional Supabase URL for anonymous analytics)*
   - `VITE_SUPABASE_ANON_KEY`: *(Client-Side: Optional Supabase Anon Key)*
6. Click **Deploy**!
